# 数据与隐私

[返回首页](../README.md)

插件没有自建服务器、遥测或主动上传功能。草稿、CSS 历史、配置恢复点保存在本库的插件 `data.json`，旧片段备份保存在配置目录；它们可能随用户启用的库同步服务同步。不要分享整个已安装插件文件夹或备份目录。

分享外观请使用面板中的「导出」：只导出经过白名单校验的外观参数、强调色和你填写的配置名称。配置名称也会公开，请勿填入私人信息。

启用第三方 CSS 后，其中的外部字体、图片、`url()` 或 `@import` 可能向外部服务发送网络请求。插件保留 CSS 原文及原生加载行为，没有实现网络拦截，也不能保证第三方片段离线。请检查来源和外部资源地址。停用插件不会停用 Obsidian 已启用的片段。

## 安装与分享文件

安装或升级只需要 `main.js`、`manifest.json`、`styles.css`。请保留原来的 `data.json`，也不要将它附在问题报告中。卸载时删除整个插件文件夹，会同时删除草稿、历史和配置恢复点。

截图前检查笔记内容、库名、文件路径及账号信息。反馈问题时优先使用空白测试库、最小复现笔记和经过检查的 CSS。
