# 使用指南

[返回首页](../README.md)

## 设置怎么用

点击刷子图标进入右侧「外观设置」。设置按对象组织：窗口与界面、正文与页面、标题、列表与引用、代码、表格、图片与提示框、链接/标签/高亮、文件树/标签页、小屏与窄栏。颜色、尺寸和间距放在各自对象下，不再分为“颜色区”和“进阶细节”。

- 数值项的「跟随 Obsidian」表示不覆盖该项，使用默认主题的原生规则，不会继承旧的笔记视觉系统。
- 颜色项可选跟随 Obsidian、强调色、自选颜色、次要文字色。强调色取自「窗口与界面 → 强调色」，自选支持色块与十六进制色号。
- 「标题」下有文档标题和 1-6 级标题。每级包含颜色及浓度、大小、字重、行高、上方间距、下方间距；本级恢复默认不会修改其他级别。
- 编辑器保留可编辑空行。标题下留白会扣除一个已有空行的占用，但不能压缩连续编辑空行。
- 正文紧凑/舒展预设只调整正文行高与段落间距，不再改变标题缩放。
- 默认遵循 Obsidian 原生的缩减栏宽行为。长文、清单样式只作用于指定笔记：在笔记属性中添加 `cssclasses`，长文填入 `note-prose`，清单填入 `note-list`。
- 设置分组可折叠，搜索自动展开命中项，清空后恢复展开状态。

每项修改独立保存。插件设置中的总开关暂停全部内置效果，保留参数。关闭插件会删除所有工作区文档中的内置样式；自定义 CSS 仍属于 Obsidian 原生片段系统，不随插件停用。

## CSS 与内置设置的优先级

4.1 起，对同一元素、同一属性的冲突，已启用的自定义 CSS 优先于内置设置，内置自定义值优先于默认主题。调整内置参数或改变加载先后不会抢回片段的覆盖；停用片段恢复内置值，内置恢复默认则撤销该项覆盖。

- CSS 文件不被改写，原生开关、保存和外部编辑仍可用。仅在运行时生成与内置声明重叠的优先级规则。
- 媒体查询、支持查询、容器查询、伪元素、CSS 嵌套和片段之间的选择器/层叠层/重要性顺序得到保留。
- 规则仍需命中正确元素。写在 `body` 上的变量不等于写在笔记视图上的同名变量；祖先继承不会自动变成直接覆盖。不同的属性也不会被强行视为同一项。
- 不涉及内置控制的属性继续使用原生层叠。含 `revert` / `revert-layer` 的属性保留整个原生回退过程，不强制提升。
- 浏览器不可读取的跨域 `@import` 保持原生行为；原生窗口材质 API、内联 `!important` 与其他插件强制样式不在保证范围内。宿主缺少片段注册接口时会提示降级。
- 关闭插件会移除内置与优先级规则，原生自定义片段继续存在。

## 分享配置

顶部「导出」保存 JSON 文件或复制文本；「导入」支持文件与粘贴，显示具体变更后再应用，并保留一份导入前恢复点。「撤销上次导入」恢复该配置，也会替换导入后的手动调整；成功撤销后入口收起。可取消导入强调色。

当前分享格式版本为 2，可导入版本 1 的旧配置并自动转换。参数白名单和范围会被校验；未知格式、未知字段、不完整设置、无效颜色和超过 128 KB 的文件会被拒绝。分享文件不包含笔记、CSS 源码、草稿、历史、库路径或面板布局。

## 平台适配

同一个安装包按当前平台生成设置界面和运行时样式，无需手动选择设备类型。

| 设置 | macOS 桌面 | Windows / Linux 桌面 | iOS / iPadOS / Android |
| --- | --- | --- | --- |
| 正文、标题、列表、代码、表格、图片、配色、文件树 | 显示 | 显示 | 显示 |
| 小屏与窄栏 | 显示，按笔记容器宽度生效 | 显示，按笔记容器宽度生效 | 显示，按笔记容器宽度生效 |
| 桌面标签栏、状态栏 | 显示 | 显示 | 隐藏，不生成内置覆盖 |
| 原生窗口材质及透明度 | 显示，检查当前窗口接口 | 隐藏，不调用原生材质接口 | 隐藏，不调用原生材质接口 |

macOS 全屏、系统减少透明度/高对比度或窗口接口不可用时，材质控件禁用并说明原因；恢复可用状态后重新启用。平板采用移动端布局策略，不仅凭宽度判断为桌面。正文与文件树不会因为平台不同而整组关闭。

隐藏设置只影响当前设备的显示和执行，不删除保存的值。同步到不支持的设备后，回到原设备仍保留原来的设置。配置导入会列出不适用的变更，跳过这些项目并保留原值；导出仍保留完整配置。此规则不限制用户自行编写的 CSS。

运行时按每个窗口判断能力，支持移动布局切换和独立弹出窗口。

平台逻辑与界面已通过浏览器模拟；Windows、iOS/iPadOS、Android 的原生控件、输入法、文件选择器及系统外观仍需真机验证。

## 窗口效果

macOS 桌面使用原生窗口材质；玻璃深色使用 hud，浅色使用 under-window，磨砂使用 sidebar，通透使用 under-window。面板中的背景透明度越大越透明，0% 为实色。升级时原不透明度 45% 显示为透明度 55%，实际效果不变；导入预览也使用透明度。透明度只调整底色，不改变前景文字的透明度；系统材质决定背景模糊，没有伪造的模糊半径滑块。全屏、减少透明度和不支持的平台保留实色降级。仅控制已附着工作区窗口，退出插件恢复原材质。

不同系统和字体下不承诺像素一致；不开发第三方主题兼容分支。移动端、平板、多尺寸和弹出窗口仍属于适配范围。

## 管理与编辑

- 搜索名称；按全部、启用、停用、有草稿筛选。
- 新建、复制当前编辑内容、重命名、移入回收站。新片段和副本默认停用。
- 重命名迁移启用状态与草稿；存在未保存草稿时禁止删除。
- 快速搜索弹窗：Enter 打开，Shift+Enter 启用/停用。
- 源码编辑：语法着色（含中文变量）、自动换行、查找、缩进、行列位置。
- Ctrl/Cmd+S 保存；Ctrl/Cmd+F 查找；Tab 缩进；选区 Shift+Tab 反缩进；Esc 后 Tab 离开编辑器。光标没有选区时 Shift+Tab 返回上一个控件。
- 使用真实按钮和输入控件；支持键盘焦点、浅深色和窄分栏；触摸目标至少 44px。
- 使用当前库的配置目录，不强制假定名称为 `.obsidian`。

## 修改保护与恢复

保存队列串行执行。每次保存只确认已写入的文本快照，保存期间的新输入继续保持未保存状态。同一个插件实例的多个面板共用文件会话。

草稿在停止输入 300 毫秒后存入插件 `data.json`，关闭面板时再次写入。关闭自动保存也会保留草稿。恢复的草稿与历史版本暂停自动保存，检查后手动保存。突然退出仍可能丢失最后约 300 毫秒或尚未完成磁盘写入的内容。

保存前比较磁盘内容与编辑基线；发现外部修改或删除时停止写入，保留草稿。可「读取磁盘版本」或「另存副本」。CSS 变化事件、窗口获得焦点、手动刷新和自定义 CSS 页打开时每 8 秒检查负责更新外部状态。没有跨进程文件锁，外部编辑器/iCloud 恰在检查与写入之间修改仍有极短竞态窗口；不要在多个设备同时编辑同一片段。

每次覆盖保存、放弃草稿、恢复历史或删除前留存版本。历史保存在 `data.json`，每文件最多 10 份、全库最多 50 份。可以先查看内容，再恢复为草稿或新副本。历史不等于长期备份，卸载时删除插件目录也会删除这些数据。

删除通过移动到库内 `.trash/snippet-editor/` 实现，不提供永久删除降级。删除前历史也可恢复为新文件。回收站不会自动清空。

片段开关与强调色使用 Obsidian 当前内部接口，并集中在适配层；接口不可用时显示明确提示，请改用原生外观设置。

## 已有配置与 CSS

已有插件参数和旧版分享配置仍可读取，并转换为当前设置格式。新安装默认跟随 Obsidian，不扫描、迁移或归档旧 CSS，也不会根据片段文件名停用某组内置效果。

旧 CSS 按普通自定义片段管理。启用后通过 CSS 优先级生效；如果不再需要，请在「自定义 CSS」中自行停用。已有备份文件和旧迁移记录不自动删除或执行。
