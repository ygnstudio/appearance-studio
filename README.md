# 外观工坊 · Appearance Studio

在 Obsidian 默认主题上，按自己的习惯调整笔记排版、颜色和界面细节。不懂 CSS 也能逐项设置；需要进一步定制时，可以在同一个面板管理和编辑 CSS 片段。

## 能做什么

- 调整正文、六级标题、列表、引用、代码、表格和图片，颜色、尺寸与间距放在对应设置下。
- 自定义文件树、标签页和窄栏布局，设置分组支持搜索、展开与折叠。
- 在 macOS 上使用原生玻璃材质，背景透明度可调，文字保持清晰。
- 导入、导出外观配置，应用前查看变更，导入后可以撤销。
- 编辑、启停和搜索 CSS 片段，保留草稿、保存历史，并检测外部修改冲突。

只适配默认主题的浅色和深色外观。界面目前为中文；不同平台会隐藏不支持的设置。本文描述当前源码，版本变化见 [更新记录](CHANGELOG.md)。

## 开始使用

当前提供手动安装。插件声明最低 Obsidian 版本为 1.7.2，实际桌面验证使用 1.14.3；更早版本及其他平台的验证范围见下文。

1. 在本仓库点击 **Code → Download ZIP**，解压源码。
2. 打开库的配置目录，通常是 `.obsidian`，进入 `plugins` 并创建 `snippet-editor` 文件夹。
3. 将仓库根目录的 `main.js`、`manifest.json`、`styles.css` 放入该文件夹。无需复制整个仓库，也无需构建。
4. 重新加载 Obsidian，在「设置 → 第三方插件」中启用 **Appearance Studio**。
5. 点击刷子图标打开右侧面板，从「外观设置」开始。

升级时只替换上述三个文件，保留 `data.json`。安装目录沿用 `snippet-editor`，以便保留旧版配置；不要同时安装两份。

## 设置与平台

「跟随 Obsidian」表示撤销该项内置覆盖，恢复默认主题规则。已启用的自定义 CSS 与内置设置冲突时，对同一元素的同一属性，优先级为 **自定义 CSS → 内置设置 → 默认主题**；继承、外部导入及原生窗口接口等边界见 [使用指南](docs/USER_GUIDE.md)。

| 平台 | 排版、配色、文件树及 CSS | 桌面标签栏、状态栏 | 原生窗口材质 |
| --- | --- | --- | --- |
| macOS | 支持 | 支持 | 支持，受系统与窗口状态限制 |
| Windows / Linux | 支持 | 支持 | 不提供 |
| iOS / iPadOS / Android | 支持 | 隐藏 | 不提供 |

背景透明度越大越透明，模糊程度由系统材质决定。Windows、Linux 和移动端的能力筛选已做自动化模拟测试，原生控件、输入法和文件选择器仍需真机验证。不承诺各系统像素一致，也没有做比主题更省资源的性能对比。

## 数据与隐私

插件没有遥测、自建服务器或主动上传功能。配置、草稿和历史保存在当前库内，可能随你的库同步服务同步。外观分享文件只包含外观参数、强调色和配置名称。

第三方 CSS 中的字体、图片和外部导入可能产生网络请求。分享配置请使用面板的「导出」，不要分享整个已安装插件目录。详细说明见 [数据与隐私](docs/PRIVACY.md)。

## 开发

需要 Node.js 18 或更新版本。构建与逻辑测试不依赖第三方 npm 包。

```sh
git clone https://github.com/ygnstudio/appearance-studio.git
cd appearance-studio
npm run check
npm run package
```

修改 `src/` 后运行 `npm run build`，生成插件入口 `main.js`。`npm run package` 会检查版本、运行逻辑测试，并生成只含三个安装文件的独立目录。
